Голосовой поиск фильмов и сериалов для Android TV приставок и Android-проекторов. Нажали кнопку на пульте, сказали «Во все тяжкие» — и сериал открывается в NUM или Lampa, без набора текста.

## Что умеет

- **Поиск голосом или текстом** по каталогу TMDB: постеры, год, рейтинг, фильм или сериал.
- **Карточка фильма** с описанием и кнопками приложений.
- **Переход в приложение:**

  | Приложение | Что откроется |
  |---|---|
  | NUM | карточка этого фильма |
  | Lampa | карточка этого фильма (Lampa запускается около 30 секунд). Подходят обе сборки — `top.rootu.lamps` и `ru.twicker.lampa`, кнопка сама берёт установленную |
  | Prisma | карточка выбранного фильма или сериала |
  | Flux | карточка выбранного фильма или сериала |
  | SmartTube | поиск по названию на YouTube |
  | LazyMedia Deluxe | поиск по названию в её каталоге |

  Кнопки внизу главного экрана работают сразу из результатов: NUM, Lampa, Prisma и Flux открывают верхний результат, SmartTube и LazyMedia ищут по запросу.
- **История** — кнопка справа от строки поиска. Хранит 20 последних открытых карточек: вышла новая серия — открыли сериал из истории, не произнося название заново.
- **Управление с пульта**, в том числе с радиопульта с USB-приёмником.

## Установка

1. Скачайте `say-and-watch-1.1.0.apk` со [страницы релизов](https://github.com/aleksandrgrn/say-and-watch/releases/latest) и установите.
2. Для голоса нужен **Speech Services by Google** (распознавание речи). Без него работает поиск текстом.
3. При первом запуске приложение попросит **ключ TMDB**: бесплатно на [themoviedb.org](https://www.themoviedb.org/settings/api), 32 символа.
4. Нажмите кнопку голосового поиска на пульте. Если система спросит, каким приложением выполнить действие, выберите «Голосовой поиск» → «Всегда».

В списке приложений оно появится как «Голосовой поиск».

## Где проверено

Нужен Android 9 или новее. Экран подстраивается под разрешение: на 720p и на 1080p карточки и кнопки одного размера.

| Устройство | Android | Экран |
|---|---|---|
| Проектор TD80 Pro | 13 | 1280×720 |
| Приставка TX9s | 9 | 1920×1080 |

## Как это работает

```text
кнопка на пульте → распознавание речи → поиск в TMDB → карточка
                                                        ├─ NUM / Lampa / Prisma / Flux: ссылка на карточку TMDB → карточка фильма
                                                        └─ SmartTube / LazyMedia: поиск по названию
```

Карточки NUM, Lampa, Prisma и Flux используют идентификаторы TMDB, поэтому они открывают фильм точно. У SmartTube и LazyMedia каталог свой, туда уходит название.

## Сборка из исходников

```bash
./gradlew assembleRelease
```

Подпись release-сборки берётся из `local.properties` (`td80.keystore.path`, `td80.keystore.password`, `td80.key.alias`); без них Gradle соберёт неподписанный APK. Ключ TMDB в release не вшивается — пользователь вводит свой.

Kotlin, minSdk 28, OkHttp + Moshi, Coil, SpeechRecognizer. Тесты: `./gradlew testDebugUnitTest`.
